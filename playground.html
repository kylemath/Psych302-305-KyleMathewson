The tool computation before the mind computation

Structure, style, behavior.

A webpage is already a three-part model of a psychological experiment: what is there, how it appears, and what it does when someone acts. Tonight is only this. Next week those three layers become a visual search task.

page = HTML + CSS + JavaScript Tonight’s remix: change one layer at a time and say what changed in the experience.

Three building blocks

<h1> <button>

HTML is the skeleton: headings, marks, buttons, the things a participant can see or click.

  • In an experiment this is the trial structure.
  • In a composition this is the inventory of forms.
  • If you delete an element, it is gone. That is an independent variable.
color: gold; padding: 20px;

CSS is appearance: color, spacing, rhythm, figure and ground.

  • Arts students already speak this language.
  • Science students should treat palette as a factor, not a theme.
  • Next week, color is what makes a target pop out.
click addEventListener

JavaScript is behavior: it notices an action and changes the world.

  • This is also how we record a reaction time.
  • A click is a response. A timer is a dependent variable.
  • You do not need to be a programmer to change one line and see the mind of the page change.
