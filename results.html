One claim and a figure

Build a short HTML page from data you already have: a sentence, a figure or table, and a limit. The graded work tonight is the individual midterm check-in. There is no peer critique.

The page

What to put on it

  1. A title that states the measure.
  2. The prediction you wrote before looking.
  3. One figure or table (screenshot from Week 5, or the optional descriptives page, is enough).
  4. A result sentence that a stranger can understand.
  5. A limitation, including n.

Save it as project/results.html in your private repository.

The check-in

Due in class

Copy project/CHECKIN.md. State the question, the taught tool, one prediction, and the files that already exist. If the project has more than one test, reduce it.

The 15% grade is the check-in file, not a presentation. The weekly report is separate: path to the results page and the claim.

Remix

Modification

A classmate should see the claim sentence before they hunt for a chart. State n and one limit on the page. A difference without a count is a caption, not a result.
