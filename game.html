The instrument

Question first, then the game

Tonight’s n is still small. That is not the week’s lesson. The tool is a browser game that can study a question: it presents two conditions, records a response and a time, and writes a CSV you can reopen in Week 5 or in the final project.

A game without a logged comparison is a toy. This page withholds on a mint square so you can count false alarms against go misses.

Modification
