Once, on your laptop

Install VS Code, Git, and Python 3

All three are free. Do not buy Copilot or enter a credit card.

  1. Visual Studio Code. Download from code.visualstudio.com and install. Open it once so it finishes setup. If it later asks to Reopen in Container, choose Don’t Reopen.
  2. Git. git-scm.com/downloads. On a Mac, if Terminal asks you to install command-line tools, agree. On Windows, the default options are fine.
  3. Python 3. python.org/downloads. On Windows, tick Add python.exe to PATH before you click Install. In VS Code: Terminal → New Terminal. Check with python3 --version (Mac / Linux) or py -3 --version (Windows). You need 3.10 or newer.
Week 4, on your laptop

Install Typst

Typst is one free compiler. It turns main.typ into a PDF. It is not a website and it is not LaTeX. Check first with typst --version in the VS Code terminal.

  1. macOS. If you have Homebrew: brew install typst. If not, download the aarch64-apple-darwin (Apple silicon) or x86_64-apple-darwin (Intel) archive from GitHub releases and put the typst binary somewhere on your PATH (for example /usr/local/bin).
  2. Windows. In PowerShell: winget install --id Typst.Typst. Close and reopen the VS Code terminal, then typst --version. If winget is missing, download the Windows zip from the same releases page and add that folder to PATH.
  3. Compile. From week04-report/: typst compile main.typ output/main.pdf. Open that PDF. The Results table and figure must come from output/numbers.typ and output/figure.png, which the Python script writes after pip install -r requirements.txt in the local .venv — not on the system Python.

The VS Code extension Tinymist Typst is optional. You do not need it if the terminal command works.

Every week, in class

The weekly recipe

  1. Open this week’s folder (make a new weekNN-… folder the first time that week needs one).
  2. Do the laboratory on the handbook page for that week.
  3. Write README.md in that folder — prediction first, before you look at a result.
  4. Drop any CSV (and any page you edited, with its stylesheet or other dependencies) into the same folder.
  5. Commit and Sync. Source Control (branch icon) → a short message → Commit → Sync / Push. Check that every file the page needs (for example a linked .css) is staged, not just the page itself.
  6. Hand in on Canvas. Paste the path to that week’s README.md, the lines that week’s assignment asks for, and your AI disclosure. A push that is not pasted on Canvas is not submitted.

Still have loose Week 0–2 files in the repo root (rt.html, lab-notes/, data/)? Move them into week02-rt/ once — after that, everything lives in its own week folder.

Each week’s Canvas assignment states that week’s specific files and questions; this recipe does not change week to week.

Week 1 discussion · used all term

Agentic coding

An agent can propose an edit, run a command, and show you the result. That does not make the report its work. You choose the question, you keep the files, you read the output, and you decide what stays.

Strategies that work in this course

  • Small asks. “Exclude RTs under 150 ms” is better than “write my lab.”
  • Name the file. Point at this week’s README.md or CSV. Do not paste the table into the chat.
  • Run what it wrote. If you cannot run it, you do not yet have a result.
  • Read the number. If n is 0 or the mean is 12 ms, the file is wrong. Fix the file, not the sentence.
  • Keep a trail. A commit, or two sentences in the report, of what you asked and what you changed.

What we do not do

  • Paste classmate rows, names, or a whole CSV into a prompt.
  • Accept a bibliography or a mean you have not opened or recomputed.
  • Buy Copilot, Cursor, or any paid plan for this course.
  • Submit a page you cannot explain.
