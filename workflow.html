Week 2 tonight · Codespace

How you work this week

Yes: you edit the note, change the task, and run your own HTML page inside the Codespace. github.dev (press period) can edit files but cannot run the page. Use a Codespace for the block. Everyone does the same assignment.

  1. Open the private repo. On GitHub, go to kylemath/psych302-305-YOURUSERNAME (accept the invite first if you have not). This is not your Week 1 public homepage repo.
  2. Start a Codespace. Green Code button → Codespaces → Create codespace on main (2-core is enough). Wait until the file tree appears on the left.
  3. Make the note. In the terminal at the bottom (Terminal → New Terminal if it is hidden), run cp lab-notes/TEMPLATE.md lab-notes/week02.md. Open lab-notes/week02.md and write your predicted mean now, before any scored trial.
  4. Remix on the class sandbox. Open rt.html (this handbook). Change a number or the drawing, click Run, try Practice. When you like it, Copy sketch.
  5. Paste into the Codespace. Open rt/rt.html and replace the script (below the paste comment) with what you copied. Save.
  6. Serve your copy. In the Codespace terminal: python3 -m http.server 8765 --bind 0.0.0.0. Ports → 8765 → Open in Browser, then go to /rt/rt.html. Click the page, Start, run the scored block, Export CSV.
  7. Put the CSV in the repo. Export saves to your laptop’s Downloads folder. Drag that file into the Codespace data/ folder (or right-click data/ → Upload). Rename it if you like, e.g. data/week02.csv.
  8. Finish the note. Add what you changed in the code, then n, mean RT, SD, and one limitation from the export.
  9. Commit and push. Left sidebar Source Control (branch icon) → message such as week 2 rt → Commit, then Sync / Push. Leave the server running until you have the CSV; you can stop it with Control-C in the terminal.
  10. Hand in on Canvas. Open Week 2 · Laboratory report, paste the five asked lines, click Submit. A push that is not pasted is not submitted.

First hour is still the class p5.html studio (lesson only). The class rt.html is the remix sandbox. Your grade is the sketch you paste into rt/rt.html. Rubric: rubrics.html.

If Codespaces is unavailable

Alternatives (in order)

  1. Codespace — preferred.
  2. github.dev — press period (.) to edit files only. It cannot run rt/rt.html. Come back to a Codespace for the block.
  3. ZIP download — edit locally; push later with assistance if needed.
  4. Open the HTML file on your laptop — last resort if Codespaces is down; still push the edited file and CSV into the private repo before Canvas.
Week 1 discussion · used all term

Agentic coding

An agent can propose an edit, run a command, and show you the result. That does not make the report its work. You choose the question, you keep the files, you read the output, and you decide what stays. The same loop appears in Week 4 without any assistant: edit a file, run a script, read the paper, edit again.

Strategies that work in this course

  • Small asks. “Exclude RTs under 150 ms in summarize.py” is better than “write my lab.”
  • Name the file. Point at report/REPORT.md or data/week02.csv. Do not paste the table into the chat.
  • Run what it wrote. If you cannot run it, you do not yet have a result.
  • Read the number. If n is 0 or the mean is 12 ms, the script is wrong. Fix the file, not the sentence.
  • Keep a trail. A commit, or two sentences in the report, of what you asked and what you changed.

What we do not do

  • Paste classmate rows, names, or a whole CSV into a prompt.
  • Accept a bibliography or a mean you have not opened or recomputed.
  • Buy Copilot, Cursor, or any paid plan for this course.
  • Submit a page you cannot explain. If you cannot say what the script excluded, redo that part by hand.

Week 1: we discuss this after the playground. Week 4: report.html is the first graded loop. Later weeks: same disclosure on every report.
