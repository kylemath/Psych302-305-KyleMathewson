Once, on your laptop

Install VS Code, Git, and Python 3

All three are free. Do not buy Copilot or enter a credit card. Install before you start Week 2.

  1. Visual Studio Code. Download from code.visualstudio.com and install. Open it once so it finishes setup. If it later asks to Reopen in Container, choose Don’t Reopen — we work on the laptop, not in a container.
  2. Git. git-scm.com/downloads. On a Mac, if Terminal asks you to install command-line tools, agree. On Windows, the default options are fine.
  3. Python 3. python.org/downloads. On Windows, tick Add python.exe to PATH before you click Install. In VS Code: Terminal → New Terminal. Check with python3 --version (Mac / Linux) or py -3 --version (Windows). You need 3.10 or newer.

Week 2 · VS Code on your laptop

How you work this week

You edit the note, change the task, and run your own HTML page from the cloned folder. Everyone does the same assignment.

  1. Open the cloned repo in VS Code (File → Open Folder if it is not already open).
  2. Make the note. Open lab-notes/TEMPLATE.md, then File → Save As lab-notes/week02.md. Write your predicted mean now, before any scored trial.
  3. Personalize the task. Open rt.html (this handbook). Modify the sketch so it is clearly yours — look, timing, labels, or procedure — then Run and try Practice. A single number change is not enough. Copy sketch when you are happy.
  4. Paste into your copy. In VS Code, open rt/rt.html and replace the script (below the paste comment) with what you copied. Save.
  5. Serve your copy. Terminal → New Terminal (leave the working directory at the repo root, the folder that contains lab-notes and rt), then: python3 -m http.server 8765 (Windows: py -3 -m http.server 8765). In your browser open http://127.0.0.1:8765/rt/rt.html. Click the page, Start, run the scored block, Export CSV.
  6. Put the CSV in the repo. Export saves to your laptop’s Downloads folder. Drag that file into the data/ folder in VS Code (or copy it there in Finder / File Explorer). Rename it if you like, e.g. data/week02.csv.
  7. Finish the note. Say how you personalized the task, then n, mean RT, SD, and one limitation from the export.
  8. Commit and push. Left sidebar Source Control (branch icon) → message such as week 2 rt → Commit, then Sync / Push. Leave the server running until you have the CSV; you can stop it with Control-C in the terminal.
  9. Hand in on Canvas. Open Week 2 · Laboratory report, paste the five asked lines, click Submit. A push that is not pasted is not submitted.

First hour is still the class p5.html studio (lesson only). The class rt.html is the remix sandbox. Your grade is the sketch you paste into rt/rt.html. Rubric: rubrics.html.

Week 1 discussion · used all term

Agentic coding

An agent can propose an edit, run a command, and show you the result. That does not make the report its work. You choose the question, you keep the files, you read the output, and you decide what stays. The same loop appears in Week 4 without any assistant: edit a file, run a script, read the paper, edit again.

Strategies that work in this course

  • Small asks. “Exclude RTs under 150 ms in summarize.py” is better than “write my lab.”
  • Name the file. Point at report/REPORT.md or data/week02.csv. Do not paste the table into the chat.
  • Run what it wrote. If you cannot run it, you do not yet have a result.
  • Read the number. If n is 0 or the mean is 12 ms, the script is wrong. Fix the file, not the sentence.
  • Keep a trail. A commit, or two sentences in the report, of what you asked and what you changed.

What we do not do

  • Paste classmate rows, names, or a whole CSV into a prompt.
  • Accept a bibliography or a mean you have not opened or recomputed.
  • Buy Copilot, Cursor, or any paid plan for this course.
  • Submit a page you cannot explain. If you cannot say what the script excluded, redo that part by hand.

Week 1: we discuss this after the playground. Week 4: report.html is the first graded loop. Later weeks: same disclosure on every report.
