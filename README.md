# PSYCH 302 / 305 · Computational Methods in Psychology

University of Alberta, Fall 2026. Cross-listed Science (302) and Arts (305). Wednesday 18:00–21:00.

The course teaches **computing tools** (repository, Codespace, git, data files, generated reports) using **ordinary psychology** as the examples (reaction time, inventories, a report pipeline, documentation). It is not a survey of mathematical psychology.

**Canvas** is the official course: https://canvas.ualberta.ca/courses/35483

**Handbook:** https://kylemath.github.io/Psych302-305-KyleMathewson/

## Assessment

- **50%** weekly laboratory reports (weeks 1–9, drop the lowest). Tuesday 17:00.
- **15%** individual midterm check-in, 28 October.
- **35%** individual final project, 2 December.

Marking schemes: [rubrics.html](rubrics.html). Official late work and letter grades: Simple Syllabus on Canvas. No graded group work and no graded peer review. Week 0 is complete/incomplete and omitted from the average.
