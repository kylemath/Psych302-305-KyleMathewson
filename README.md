# PSYCH 302 / 305 · Computational Psychology Studio

Proposed design for a 300-level, lab-based, 3-hour weekly session cross-listed between Psychology (Science, 302) and Arts (305).

The class is built around a small number of computations, not a tour of programming languages. Each Wednesday-night-length block teaches one equation, lets students become the subject, then asks them to remix the display as both an experiment and a composition.

## The computations

| Week | Computation | Page |
| --- | --- | --- |
| 1 | `page = HTML + CSS + JS` | [playground.html](playground.html) |
| 2 | `RT = a + bN` visual search slopes | [search.html](search.html) |
| 3 | `d′ = z(H) − z(FA)` | [sdt.html](sdt.html) |

Week 2 is the signature lab. Feature search should stay near 0 ms/item. Conjunction search should cost time as set size grows. That is Feature Integration Theory as a number a mixed-major room can argue about.

## How to run a session

Open the HTML files in a browser. No install, no build, no accounts.

1. Frame the equation for 25 minutes.
2. Run the page once as a demo.
3. Students complete a block and read their own slope or d′.
4. Break.
5. Compute and write one interpretive sentence.
6. Remix: Arts changes the field; Science adds a factor.
7. Four-minute critique.

A 6-trial demo exists on the search page for the instructor walkthrough. The full block is 36 trials.

## Why this and not a methods lecture

- 300-level prereqs are intro plus one 200-level course, not calculus or coding.
- A 3-hour single session dies if the first hour is software setup.
- Cross-listing only works if aesthetic decisions are treated as independent variables.
- Kyle’s existing playground already taught the three web layers; this repo keeps that as night one and spends night two on a mind, not on syntax.
