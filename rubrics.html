Rubrics

Official weights, late work, and letter grades live on the Simple Syllabus in Canvas. This page is the marking scheme only. Partial credit is the default. Fashion, extra features, and how long you speak in class are not graded.

50% weeklies · 15% check-in · 35% final Drop the lowest weekly. Week 0 is complete / incomplete and omitted.
10 points · weeks 2–9

Weekly laboratory report

Paste the requested lines on Canvas. The file itself lives in your private course repository. Copy lab-notes/TEMPLATE.md.

2 · File
The path you pasted opens a note (and a CSV in data/ when the lab collected data).
3 · Prediction or asked content
You answered the week’s question in your own words, written before or apart from the result.
3 · Result
A number, short table, or claim that comes from your file — not typed from memory or a chatbot.
1 · Limitation
One reason that number can lie (practice, anticipation, self-report, small n).
1 · Disclosure
AI use named, or the line no Copilot tonight.

Zero on a row if that piece is missing. Pasting classmate names or raw classmate data is a zero on Result. Late weekly reports are not accepted unless an accommodation is already in place; the dropped week covers one miss.

10 points · due Tuesday 8 September, 17:00

Week 1 exception

Week 1 is a publishing lab, not a CSV. We mark the four GitHub steps and that you named three personal changes. Commit style is not graded. One pull request will be merged as the class homepage; the rest will be closed. Closing a PR is not a penalty.

2 · Own repository
A repo on your account with your index.html. The link opens.
2 · GitHub Pages
https://YOURUSER.github.io/YOURREPO/ shows your page, not a 404.
2 · Fork
A fork of the whole class handbook, with your page as that fork’s index.html. Other course files still there.
2 · Pull request
A PR from that fork into kylemath/Psych302-305-KyleMathewson.
1 · Three changes
You named three ways the page is about you.
1 · Disclosure
AI use named, or no Copilot tonight.
15 points · 28 October, in class

Midterm check-in

Individual. File project/CHECKIN.md in your private repository and paste the five lines on Canvas. If the project has more than one test, reduce it before you submit.

4 · Question
One sentence. One comparison or one measure a stranger can restate.
3 · Taught tool
Reaction time, inventory, comparison, a methods-and-results page, or a browser game that studies a question. No new library.
4 · Prediction
A direction or expected pattern, written before new data. The check-in date is the timestamp.
2 · What already exists
Real files in your repository (CSV, earlier note, draft page).
2 · Scope and risk
What you will build by 2 December, and one thing that could fail.
35 points · 2 December, end of class

Final project

The page is the examination. There is no registrar exam and no graded talk. Self as participant by default. Checklist: project/FINAL.md.

8 · Running page
A stranger can open it and state the measure or claim without you in the room.
7 · Prediction
The midterm check-in counts if you did not change the question. If you did, say so.
8 · Result
One figure or table and one sentence that states the claim.
7 · Limitation
Includes what your n can and cannot support.
3 · Data
A file in data/ if you collected any. Write no new data if the page reuses an earlier CSV.
2 · Disclosure
AI use named, or no Copilot tonight.

Not graded: framework fashion, extra features for their own sake, classmate data, a statistical test beyond descriptives you can explain, or an in-class demo.
