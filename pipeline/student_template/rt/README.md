# Week 2 · your reaction-time page

This folder is a copy of the class instrument for you to edit.

1. Open `rt.html` in a browser (Codespace Simple Browser, or double-click the file).
2. Change at least one visible thing (mark colour or size, keys, delay, trial count, or a label).
3. Write a predicted mean in `lab-notes/week02.md` *before* the first scored trial.
4. Run a simple-RT block on **this** page, not only the class handbook page.
5. Export the CSV into `data/`.
6. Push the repo, then paste the paths on the Week 2 Canvas assignment.

How to submit: https://kylemath.github.io/Psych302-305-KyleMathewson/workflow.html#submit
