Week 2 · Wednesday 9 September 2026
p5.html · rt.html

Tool: p5.js pieces, then a timed response and a CSV

First hour: six short p5.js sketches (pixels, refresh rate, variables, a stimulus, buttons, one timed click). Then the real instrument: a simple reaction-time sandbox you remix in p5. Anticipations under 150 ms and lapses over 2500 ms are excluded from the mean.

18:00 Introduction
A program is input, memory, and a display. We name the parts before we measure.
18:10 Studio
Walk p5.html in order. Remix a number or a string and Run.
19:15 Break
Write a predicted mean for the real block before the first trial.
19:25 Instrument
Instructor demo on the rt.html sandbox, then a simple-RT block. Export the CSV.
20:05 Modification
Personalize the task on rt.html, copy the sketch, paste into VS Code rt/rt.html.
20:45 Discussion
Toy trial vs instrument: exclusions and a file. The number comes from the export, not a chatbot.
Reading
A short note on Donders (1868). Skim.

Report: in VS Code, personalize rt/rt.html, write a predicted mean, run Simple RT on that page (http://127.0.0.1:8765/rt/rt.html), put the CSV in data/. Same assignment for everyone. VS Code walkthrough.

Week 3 · Wednesday 16 September 2026
inventory.html

Tool: VS Code folders, then edit a hardcoded instrument

First hour: clone the private repo and move Week 2 into week02-rt/. Then a ten-item teaching inventory — but every student edits their own copy (week03-inventory/inventory.html + inventory.css, already in the repo) so all ten items are their own wording. Likert responses, reverse scoring, subscale means, CSV. Classroom instrument, not a clinical scale.

18:00 VS Code
Install if needed. Clone kylemath/psych302-305-YOURUSERNAME (not a handbook fork). Rearrange Week 2 into week02-rt/.
18:40 Introduction
Self-report as data, not as a diagnosis. Open week03-inventory/inventory.html and find the ITEMS array — a hardcoded list, not a database.
19:00 Demonstration
Complete the class version once as a walk-through (inventory.html). Then rewrite one item live to show the edit-save-reload loop.
19:25 Exercise
Rewrite all ten items in your own copy (5 domains, 2 items, one reverse per pair). Write the prediction in README.md before scoring your own version.
20:05 Modification
Discussion prompt while you finish: was hand-editing ten strings inside a script tag tedious? What would you rather the items lived in?
20:45 Discussion
Commit, Sync — both inventory.html and inventory.css — and where the Canvas paste goes (due Tuesday).

Report: write week03-inventory/README.md (prediction first, then your own domain, item count, one limitation, and a tedium note). Rewritten inventory.html + inventory.css + CSV in that same folder. VS Code walkthrough.

Week 4 · Wednesday 23 September 2026
report.html

Tool: a report from Python and Typst

Example: your Week 2 reaction times or Week 3 inventory scores. In week04-report/, write the paper in main.typ, analyze the CSV and draw a figure with scripts/summarize.py, compile with typst compile. Run, read the PDF, change, run again. Do not type the mean by hand.

18:00 Introduction
A report is a pipeline. The number in the PDF must come from a file the script can read again.
18:25 Demonstration
Instructor runs build.sh on a sample CSV, opens the PDF, changes one line, compiles again.
18:40 Exercise
Install Typst if needed. First build on the sample. Then point the script at your CSV. Write the prediction first.
19:25 Results
The PDF (or the generated table) and one limitation. No draft exchange.
20:05 Modification
Rewrite the sentences until a stranger can state the claim, then change the exclusion rule or add a second descriptive and rebuild the PDF.
Reading
report/README.md and agentic coding.

Report: paths to the README, main.typ, the generated snippet, the figure, and output/main.pdf. The CSV you used. Name one iteration. Due Tuesday 29 September (no class on the 30th).
